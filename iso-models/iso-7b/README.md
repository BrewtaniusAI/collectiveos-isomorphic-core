# ISO-7B

ISO-7B is the middle OIMS weight-backed tier.

- binding: Qwen2.5-7B-Instruct GGUF
- quantization: Q4_K_M
- local download: approximately 4.7 GB across two files
- status: runtime binding implemented
- execution: `python -m oims run --tier ISO-7B --prompt "..."`;

The exact repository revision and filenames are defined in `MODEL_MANIFEST.json`.
